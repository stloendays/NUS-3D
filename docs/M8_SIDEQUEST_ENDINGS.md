# M8 — 六条支线、六种结局与剧情任务手册

本次开发在 NUS-3D 内增加独立剧情系统，整体基调是校园解压、夸张、搞笑；所有老师和同学的故事均是**虚构游戏剧情**，并不映射现实学生、学校行政流程或 NUS 官方规定。

## 游戏玩法

登录后按 **P** 打开剧情任务手册，查看每一条支线的任务目标、进度、分歧选择和结局图鉴。在界面内点击“任务 / 结局图鉴”切换面板，按 P 或 Esc 关闭，游戏继续运行。打开手册时暂停世界、竞速计时和 NPC 行动；关闭后恢复。其他 E / C / Q / X / V / Y / I 键保持原样。

任务使用既有世界事件，不新造冲突快捷键、不需要重建场景：
- E 的四站探索，C 的 8 份 Field Notes，Q 的 NPC 实际交谈
- X 乘坐校车，I 进入 ERC 室内，Y 切换下雨/雷暴
- V 结束 Campus Sprint，并取得金牌

支线先完成目标，然后在任务手册选择处理方式，才算结算任务；选择实时改变 **诚信 integrity、人缘 kindness、压力 stress**。完成**任意三条支线**可在任务手册开启“最后一秒的 DDL”终章，选择提交或彻底摆烂，结局由支线选择和状态计算。

## 六条支线

| 支线 | 核心条件 | 关键选择 |
|---|---|---|
| 咖啡能量守恒 | 找 Mei 聊天；收集一份笔记 | 早睡，还是四倍浓缩 |
| 消失的组员 | 与 Maya、Ethan 聊天 | 帮助组员，还是假装掉线 |
| 末班校车生存游戏 | 询问 Aisha；搭乘一次校车 | 让座，还是抢最后座位 |
| 实验报告去哪了 | 收集三份笔记；进入 ERC | 归还真实记录，还是抄数据 |
| DDL 紧急救援 | 四站打卡；完成一次竞速 | 如实提交，还是粉饰进度 |
| 凌晨 03:00 的校园怪谈 | Daniel、六份笔记、雨天和竞速金牌 | 打破循环，还是独占延期 |

每条支线首次结算可获得 **70 XP**。同一账号重开剧情后仍可重做任务、改选另一条故事线，但相同支线的 XP 不会重复发放。

## 六个结局（提示，不剧透全部判定）

- **好结局：校园救星** — 人缘很好、保持诚信，救回小组和实验记录。
- **好结局：DDL 幸存者** — 诚实交上自己的作业，至少扛过了这一学期。
- **坏结局：咖啡机继承人** — 压力太高、缺乏支持。
- **坏结局：学术诚信警报** — 多次选择投机造假的捷径。
- **坏结局：DDL 黑洞** — 最终选择“明天再说”，时间彻底崩溃。
- **隐藏结局：时间管理员** — 完成高难度校园怪谈，同时保有诚信与人缘。

每个结局首次解锁奖励 **150 XP**，解锁内容永久写入独立账号的结局图鉴；重开剧情不清空已有结局。

## 数据与模块隔离

- 游戏剧情数据：godot/data/story_campaign.json。所有标题、任务目标、选项、对白和结局故事均有 zh/en。
- 任务状态机：godot/scripts/story_director.gd，动态加入启动 Shell，不侵入原 main.tscn。
- 登录接入：godot/scripts/game_shell.gd，仅增加 StoryCampaign 实例、登录/退出读取状态与 P 键入口。
- NPC Q 事件：godot/scripts/utown_campus_life.gd，仅增加成功交谈时的 talked_to 信号（不会把自动随机吐槽错算为任务完成）。
- 任务提示：godot/scripts/hud.gd，将 P 快捷键加入 F1 操作帮助。
- 新手教程：godot/data/startup_tutorial.json，新增中英双语“支线任务与结局 / P”章节说明。

剧情数据保存于 `user://nus3d/challenge_<account_id>_story.json`（基于已有账号随机 ID 的独立文件，不以用户名拼路径）。保留原有挑战与账号数据，切换账号各有独立支线与结局图鉴，未登录无法进行剧情选择。

剧情可以无限重开，但同一任务/结局的 XP 使用账号层唯一 ID 防止刷经验。剧情状态和结局历史不会覆盖此前的探索笔记、竞速最佳成绩、人物等级或登录信息。

### 兼容性说明

目前这套任务复用 M7 所在分支可用的六名室外学生、ERC/SRC 场景和校园挑战；未来合并 M3 的扩展世界、新 NPC 或其它战斗/货币系统时，仅需新增事件接入，不应直接复制玩家控制器或主 HUD。正式发布前需做 Windows 图形界面的中文字体、滚动、按键焦点以及低分辨率布局测试。
