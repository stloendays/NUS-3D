# M15 — Classroom prop pass

Adds a small procedural prop kit to the existing ERC ground-floor study room: eight notebook/pen sets, four open laptops, four lidded cups, selected under-desk backpacks, a whiteboard, notice cards, marker tray and ceiling projector.

All props are non-interactive visual set dressing made from primitive BoxMesh and Label3D objects. No downloaded models, textures, physics bodies, real-time lights, save changes or network messages. The central 2.5 m aisle and upper landing remain clear.

This is a fictional classroom/study-room concept, not an architectural reconstruction of a particular NUS teaching room. Follow-up work can add exam papers, teaching podiums and optional object interactions after testing.

**Validation still required:** Godot 4.4 parse/import, in-game interior screenshots and collision/walkthrough QA. Desk top is at y=1.0, and stationery is placed just above it. Test low-spec performance before expanding to more rooms.
