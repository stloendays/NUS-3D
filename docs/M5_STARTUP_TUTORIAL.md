# NUS-3D 新手教程 / Startup guide

本教程可从 **游戏启动登录界面**直接打开，不需要先注册或登录。启动页新增 **“新手教程 / HOW TO PLAY”** 按钮。

## 教程文件（单一内容源）

- 游戏实际读取：`godot/data/startup_tutorial.json`，内含 6 个可独立维护的章节及每章的说明段落。
- 显示组件：`godot/scripts/startup_tutorial.gd`，负责全屏覆盖层、翻页、滚动、关闭和标题显示。
- 接入点：`godot/scripts/game_shell.gd`，只在登录画面展示入口，**不改动原有 3D 地图与玩法脚本**。

更新操作说明时，请修改 JSON 里的 `pages[].sections[].heading` 与 `body`；不必把整篇内容硬编码到游戏 UI。

## 六个章节

1. **开始游戏**：注册、登录、独立存档、非官方说明。
2. **移动与视角**：WASD、鼠标、Shift、Space、Esc、R、地图 M、帮助 F1。
3. **探索与任务**：四站打卡 E、收集 C、竞速 V。
4. **校园生活**：NPC 对话 Q、进出室内 I、楼层 L、设施 F、自行车 B、校车 X、天气 Y、光线 T。
5. **等级与游戏邮箱**：一次性 XP 规则、LV/XP 显示、Campus Post 邮箱 J。
6. **更多操作与提醒**：F2/F3/F4/F6/F7 的模型、拍照与 HUD 功能，以及虚构化校园提示。

阅读时可以用 **上一页 / 下一页** 导航，最后一页点击 **完成 · 返回**，或随时点击 **关闭教程**／按 **Esc** 返回登录页面。

## 不影响游戏进程

- 教程属于启动 UI 层，保留登录界面和暂停状态，且不会自动登录。
- 没有写账号数据、升级经验、邮件或旧存档。
- 原 Godot `main.tscn`、NPC、天气、挑战与角色控制逻辑均无需更改。
- 文本可滚动阅读，整个教程内容预先加载一次，翻页只更新文本节点。
- 保留 Windows 导出和 `--nus3d-self-test` 的原有启动路径；教程 JSON 应由 `res://data/` 一同打包。

## 测试

运行 `godot --headless --path godot --script res://tests/account_smoke_test.gd` 验证：启动前可打开教程、6 页齐全、上一页/下一页边界有效、关闭后仍处于暂停的登录状态，之后账号登录与既有游玩测试继续正常。

这是独立制作的非官方校园游戏，教程中的场景、路线、室内及校车内容不能当作 NUS 实际导航或交通资料。
